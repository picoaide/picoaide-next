# PicoAide 浏览器桥(Chrome MV3 扩展)

把 AI Agent 的浏览器操作转发到你自己浏览器中的当前标签页(读取内容 / 点击 / 输入 / 导航 / 滚动 / 执行 JS)。**纯本地**:直连客户端主进程的 WebSocket 服务,数据不经服务端,离线可用。

## 安装(开发者模式加载,零配置)

1. 打开 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点击 **加载已解压的扩展程序**,选择本目录 `browser-extension/`
4. 完成——无需任何设置:**插件自动直连 `ws://127.0.0.1:54321`,安装即用**

安装后图标角标显示连接状态:`on` = 已连上客户端,`off` = 未连接(客户端未启动或已退出,会自动重连)。

## 使用前提

- 客户端已启动(其 CDP 服务监听 `127.0.0.1:54321`)
- 当前活动标签页需要**刷新一次**(让 content script 注入;安装插件后已打开的旧页面需刷新)
- 浏览器内部页面(`chrome://` 等)与浏览器商店页面不可操作

## 在客户端让 Agent 操作浏览器

- 读取类(`browser_tab_info` / `browser_get_content`):直接可用
- 操作类(点击 / 输入 / 导航 / 滚动 / 执行 JS):触发审批弹窗,确认后执行

未安装插件时,Agent 会得到明确错误「浏览器插件未连接」。

## 端口说明

默认端口 **54321**。如需修改:改客户端设置页的端口,并把本目录 `background.js` 顶部的 `CDP_URL` 同步修改,然后在 `chrome://extensions` 重新加载扩展。

## 企业分发

除开发者模式加载外,可经组策略(ExtensionInstallForcelist)下发;因无托管权限,插件不含自动更新来源,更新需重新加载。
